## 🚀 Featured Projects

### 🧬 RouteX – TSP Solver (Genetic Algorithm + CPLEX)

A C++ solver for the Travelling Salesman Problem. It combines a custom Genetic Algorithm (tournament, roulette and rank selection; OX, PMX and CX crossover; four mutation operators; elitism) with optional IBM CPLEX integration to compare results against the optimal solution. Includes generation-wise logging, CSV export and Java-based graphs.

**Technologies:** C++, IBM CPLEX, Java

🔗 [View Project on GitHub](https://github.com/ani28-bit/SPL-01)

---

### 🎓 University Management System

**Technologies:** Java, Java Swing, JDBC, MySQL

🔗 [View Project on GitHub](https://github.com/ani28-bit/University-Management)
